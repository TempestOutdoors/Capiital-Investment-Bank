# Editing the Capiital site: a guide for the firm

Plain instructions for the everyday changes. Everything here is done in Elementor or the WordPress
admin. No code is needed, and nothing here can break the design. *Claude Code: keep this guide true to
what you built, and correct any step that differs.*

## Before you start

- **Change text and pictures freely.** Leave spacing, colours, fonts and animations alone. They are set
  once for the whole site, and changing them on one page makes that page drift from the rest.
- **Never switch on** Elementor's *Motion Effects*, *Entrance Animation*, *Hover Animation*, parallax or sticky
  options. The site's own quiet motion is built in.
- **Every change has two languages.** Make it in English first, then in Danish (see *Danish* below).

## Change a piece of text

1. Open the page and choose *Edit with Elementor*.
2. Click the text, change it in the left panel, and press *Update*.
3. For the hero, *Where we engage*, *What we learned* and the archive intro, the texts are fields in the
   left panel rather than on the page. Click the section and edit the fields.

## Add a publication

1. *Publications → Add new*.
2. Fill in:
   - **Title**
   - **Summary**: one sentence
   - **Body**: the text
   - **Type**, **Sector** and **Stage**: tick one each
   - **Reading time**: e.g. `12 min`
   - **Featured image**: the photograph. If you have none yet, describe the photograph wanted in
     **Photo brief**.
   - **PDF**: optional
3. Set the date, and press *Publish*. It appears at once in the archive and, if it is among the
   latest four, on the front page under *What we think*, already formatted.
4. Translate it (see *Danish*).

## Change a person

1. Edit the front page, and click the person in *Who we are*.
2. Change the photo, name, role, phone or e-mail.
   - Phone format: `M: +45 6054 4110`.
   - E-mail in lowercase.
   - Add the LinkedIn address to the *LinkedIn* link.
3. **To add a person:** right-click an existing person → *Duplicate*, then edit the copy.

## Change the observations in *What we learned*

Click the section and use the list in the left panel: *Add item*, drag to reorder, or the bin to remove.
The section adjusts its own length.

## Danish

1. Pages and publications: on the edit screen, use WPML's *Translate* (the + or pencil beside *Dansk*).
2. Translate every field. Keep line breaks where the English has them.
3. Menus, the footer and form messages: *WPML → String Translation*, then search for the English text.

## Messages from the form

They arrive by e-mail at contact@capiital.eu, and are also kept in *Elementor → Submissions* in case
an e-mail goes missing.

## The legal page

Edit it like any page. **Do not remove *[Draft for legal review]* until the lawyer has approved the
text.** Then update *Last updated*.

## If something looks wrong

Use *Elementor → Revisions* (the clock icon in the panel) to go back to an earlier version.
