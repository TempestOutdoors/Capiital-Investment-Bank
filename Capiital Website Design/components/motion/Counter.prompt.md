# Counter

A headline figure that counts up once, on entry. Display serif, tabular figures, easeOutCubic over 1.4s.

Write `value` exactly as it should read — `"90%"`, `"3x"`, `"18 mo"`, `"EUR 42M"` — and the numeric run inside it animates while the rest stays fixed. Respects `prefers-reduced-motion` by rendering the final value immediately.

Reserve it for figures that carry an argument. Two or three on a page; never on a figure inside body copy.
