One-line: generic container for UI-side content; the marketing site uses hairline-gap grids instead (see `ServiceCard`, `InsightCard`).

```jsx
<Card><CardHeader><CardTitle>Mandate summary</CardTitle><CardDescription>Q2 2026</CardDescription></CardHeader><CardContent>…</CardContent></Card>
```

CardTitle is Cormorant Garamond, not Inter. Radius is 0 despite the `xl` token name.
