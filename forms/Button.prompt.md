One-line: the brand's button — square (radius 0), `default` solid ink for UI, `editorial` hairline+wide-tracking for marketing CTAs.

```jsx
<Button>Submit</Button>
<Button variant="editorial">Our Practice →</Button>
<Button variant="outline" size="sm">Filter</Button>
```

Variants: default (ink), secondary (taupe), outline, ghost, link, destructive, editorial. Sizes: sm 32px, default 36px, lg 40px, icon 36×36, editorial (padding 20/32, tracking .28em, uppercase). Editorial hover fills taupe. Never round the corners.
